# Next 0905v3 高清图片索引

这套素材共 24 张，按 01–24 连续编号。文件名采用 `序号-next-内容-语言-明暗@2x.png`，列表与文件名使用同一顺序。

所有图片来自 0905v3 的真实 SwiftUI 组件，以原生 2× 渲染；无插值放大、无生成式重绘。账号、额度、日期均为隔离演示数据，不是真实账号截图。关于页保留适用的开源来源声明，不作为产品关联推广。

- X 配图取 05、01、02、04，最多四张就能说明这次更新。
- 小红书配图取 05、01、07、04、02、06，依次讲新界面、单账号、暖号、模型、多账号与菜单栏。

- 英文浅色设置取 15–19；英文深色设置取 20–24。

下载时打开原图后使用 GitHub 的 Download raw file，不要保存页面里的缩略预览。
