# 一个 Codex 账号，也值得装 Next

只有一个 Codex 账号，额度还要来回找？
我把 Next 更新到 0905v3 了。
这次把单账号用法和暖号时间讲清楚👇

🔹 一个账号就能看

主界面和菜单栏能看官方返回的 5 小时、7 天剩余额度与重置时间。
只看额度可以沿用当前登录，不必再注册一个账号。

🔹 一个账号也能自动暖号

主动开启后，Next 会在窗口结束且状态允许时发最小请求，尝试启动下一轮，再读官方额度。
5 小时、7 天可以分别开关。

⏰ 5 小时到底怎么算

它是额度窗口，不保证能连续工作 5 小时。
假设早上 9 点请求后，官方显示下午 2 点重置，11 点开工时离重置就剩 3 小时。

📌 时间以官方返回为准，不能保证每次都按第一条消息加 5 小时算。暖号会耗额，不会增加额度，也不会解除周限制。

⚠️ 目前仍有配置门槛

暖号默认关闭，需要 Hub 映射、可信空闲状态，Mac 也得醒着联网。免 Hub、按工作时段暖号都还没做，别装完就以为会自动运行。

🔹 模型选择少点一下

支持 GPT-6 Astra 等模型，强度和标准 / Fast 速度一起保存。
同一账号配置隔离 CLI 后，后续启动直接带参数；实际模型权限看账号，Fast 会更费额度。

🔹 多账号看这里

分别设置模型，也能应用到所有独立账号。
接入 Hub 后显示工作进行中与最近结果，忙碌或未知时关闭新入口。外部派单器也要配合，无法保证所有入口绝不冲突。

✨ 设置页也重新排了

外观、菜单栏、自动化、工作区、关于，5 个分区直接点。主题有预览，小选项直接选。

💬 你更想先做哪个

单账号免 Hub、只在工作时段暖号，还是看清哪个 Agent 在用账号？这些是征求意见，尚未上线。
