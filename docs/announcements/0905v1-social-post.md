# 只有一个 Codex 账号，也能看额度、自动暖号

Codex Account Manager Next 更新到 0905v1，加入了 GPT-6 Astra，也重新整理了单账号和多账号的界面。这是一款 macOS 原生工具，源码和高清界面图已经放在 GitHub。

如果你只有一个账号，最实用的功能很直接。

- 在菜单栏查看官方返回的 5 小时、7 天剩余额度和重置时间。
- 开启自动暖号，由 Next 在窗口结束、状态允许时发送最小请求，尝试启动下一轮计时，不用每次手动发一句话。5 小时和 7 天可以分别开关。
- 用单账号专注界面查看额度与任务模型，统计和高级设置需要时再展开。
- 查看已有的用量统计和会员有效期，调整浅色、深色、菜单栏样式与快捷键。
- 配好独立 CLI 环境后，选择 Astra 等模型、思考强度和标准或 Fast 速度，后续启动会带上这组参数，无需每次手写。

暖号为什么有用？5 小时指额度统计窗口，不代表能连续工作满 5 小时。假设早上 9 点的请求触发了新窗口，官方显示下午 2 点重置，那么 11 点开始正式工作时，距离重置剩 3 小时。Next 希望帮你减少忘记手动启动窗口的空档。

具体时间看官方返回，不能只用第一条消息时间加 5 小时来保证结果。官方公开文档说明了窗口和重置时间查询方式，没有承诺所有套餐都采用相同的首次请求起算细节。暖号会耗额，不会增加额度、提前清空旧窗口或解除周限额。规则与例子见 [5 小时窗口说明](https://github.com/BLACKIELF/codex-account-manager-next#五小时窗口与自动暖号的关系)。

只看额度可以使用当前 Codex 登录。自动暖号需主动开启，Next 保持运行、电脑醒着联网，并通过 Hub 调度服务的映射与空闲检查；5 小时暖号还受账号的“参与调度”开关控制。指定模型启动 CLI 需把同一个账号登录到隔离环境，不需要第二个账号。这段配置还可以更简单。

如果你管理多个账号，Next 更适合帮你把账号和任务状态放到一起看。

- 集中查看各账号的额度、重置时间和订阅信息，支持备注、排序与单独刷新。
- 每个账号使用隔离的 CLI 环境，模型和速度可以分别设置，也能一次应用到所有独立账号。
- 接入 Hub 后，账号卡显示待批准、工作进行中和最近结果；任务结束后的结果短暂保留，再恢复未运行。已知忙碌或状态不可信时，会关闭 Next 的新启动入口。
- 同一套自动暖号也可维护多个账号，并可按需开启低额度候选提示和飞书通知。

暖号默认关闭；刷新只读取状态。任务状态保护仍依赖 Hub，跨入口同时启动的竞争问题还需要完善，不能承诺绝对不会重复占用。

这次也把重复的巡检页移除了。额度、刷新异常和任务状态直接留在主界面，不用再切换页面找。

接下来我更想先改好三件事。

单账号能否少配置一个服务就开始工作？多账号能否看清谁在使用，避免不同入口抢同一账号？遇到失败时，能否直接看懂原因和下一步该做什么？

这些是征求意见的方向，还没有做成新功能。现阶段 Next 不会增加额度，也不会自动接管你的任务；Astra 能否使用，以账号实际开放情况为准。

你现在用一个账号，还是多个账号？如果下一版只能帮你少做一步，你最希望省掉哪一步？欢迎带着具体场景留言，或到 GitHub 提 Issue。反馈前记得去掉邮箱、凭据和任务正文。
