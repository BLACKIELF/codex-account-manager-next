Windows Dashboard Source-Hierarchy Alignment Design

2026-07-29 · Approved design · Implementation not started

Decision

macOS UsageWidgetView is the source of truth for the Windows Dashboard hierarchy. Windows will port composition and interaction order from source, not infer them from screenshots.

The Dashboard has one content navigation system: Today tasks, AI Leadership, Usage trend, Project ranking, and Skill. AI Leadership is a lower Dashboard tab. A compact overview entry may select it, but the overview does not render full leadership detail.

macOS Source Contract

  • DashboardTab contains tasks, leadership, usage, projects, and skills; its default is tasks.
  • widgetContent renders the usage overview before Dashboard tabs.
  • The overview has a compact leadership command entry, quota visual, three token cards, and month-value progress.
  • LeadershipDashboardPanel renders only when the leadership tab is selected.

Missing Windows data stays visibly unavailable. The layout will not invent quota, task, cost, or score values.

Target Structure

Dashboard window
|- Header and local-source status
|- Usage overview
|  |- Compact leadership command entry -> AI Leadership tab
|  |- Quota / reset slot with explicit unavailable state
|  |- Today / 7-day / lifetime token cards
|  `- Month-value progress
`- Dashboard content tabs
   |- Today tasks
   |- AI Leadership -> LeadershipPanel
   |- Usage trend -> UsagePanel
   |- Project ranking -> ProjectsPanel
   `- Skill -> honest unavailable state

Recent threads remain local records, not fabricated tasks. The task tab will state when a genuine task-board contract is unavailable.

Scope

Included: unified React tab state, moving complete leadership detail into its lower tab, removing home-level leadership detail, responsive grid composition, focused tests, and native visual verification.

Excluded: Rust readers, aggregation, cache, IPC, scoring, quota/task contracts, Claude Code enablement, fabricated data, and copying macOS window chrome or artwork.

Acceptance Criteria

  1. No outer AI Leadership route competes with Dashboard content tabs.
  2. Today tasks is the default tab.
  3. The sole tab bar is Tasks, AI Leadership, Usage, Projects, Skill.
  4. The compact overview leadership entry selects the lower AI Leadership tab.
  5. Leadership rail, dimensions, and trends render only in AI Leadership.
  6. Values are actual local data or explicit unavailable states.
  7. Keyboard tab navigation remains valid.
  8. Web build, Rust tests, focused layout tests, diff check, and a new native screenshot pass before visual acceptance.
