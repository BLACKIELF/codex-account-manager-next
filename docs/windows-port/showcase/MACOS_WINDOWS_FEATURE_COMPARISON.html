macOS / Windows Dashboard 功能对照（非像素复刻）

该文档按 macOS README 截图顺序组织：AI Leadership、Today、Usage、Projects、Skills。

结论标签： fixed overview、 variable panel、 partial、 not implemented、 outside Dashboard + partial。

1. 信息结构（非 Mermaid）

  • 固定总览区：macOS（Leadership + 配额/用量卡片 + 月度 Wool 进度）
  • ⇩ 结构上可对照 ⇩
  • 固定总览区：Windows（DashboardHome，Leadership + Token mix + Today/7-Day/Lifetime + rail）
  • ⇩
  • 下层可变内容槽：Tasks | Usage | Projects | Skills（macOS）
  • Windows：Leadership 为详情化独立页面，不并入四个下层可变项

2. 固定总览映射（fixed overview）

2.1 AI Leadership / Dashboard Overview

fixed overview

  • Windows 采用 DashboardHome 总览，包含 Leadership、Token mix 与多类用量指标。
  • Monthly Wool 在 Windows 当前无直接对应；Token mix 不能替代该指标。

3. 下层可变内容槽（按 README 顺序）

3.1 Tasks（variable panel + not implemented）

variable panel not implemented

  • Windows 仅有 Today 用量度量，未提供独立任务面板。

3.2 Usage（variable panel + partial）

variable panel partial

  • 用量信息有对应语义，但布局与口径不完全同构。

3.3 Projects（variable panel + partial）

variable panel partial

  • Windows 更像项目排行/邻近映射，不是同一页面结构。

3.4 Skills（variable panel + not implemented）

variable panel not implemented

  • Windows 目前仅见 Tool usage 的近似证据，独立 Skills 页面缺失。

4. 设置/配置（Dashboard 外层）

Settings / Palette（outside Dashboard + partial）

outside Dashboard + partial

  • 两端都存在配置入口，但并非 Dashboard 内同构层级；Windows 的 Light/Dark/System 与 macOS palette gallery 语义不同。

5. 结论

  • AI Leadership 为固定总览层级对应；差异在于 Windows 月度 Wool 缺口与 Token mix 口径不同。
  • Tasks 与 Skills 属于 `variable panel + not implemented`（仅最近似上下文/近似证据）。
  • Usage 与 Projects 属于 `variable panel + partial`。
  • Settings / Palette 为 Dashboard 外层 `outside Dashboard + partial`。
